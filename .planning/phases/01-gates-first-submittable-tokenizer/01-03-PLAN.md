<objective>
Wave 2 (refine the slice — serialization + reproducibility): make the tokenizer survive the two hardest invisible gates. (1) SERDE-01/02: a trained tokenizer must reload from `code/` alone in a FRESH process and round-trip encode/decode — so all learned state is plain primitives, the regex is a stored pattern string compiled in `__init__`/`__setstate__`, and the runtime encode cache is dropped via `__getstate__` and rebuilt via `__setstate__`. This turns the VP-3 check (left pending in Plan 02) green and adds the VP-5 double-run diff.

Purpose: A tokenizer that scores perfectly but won't reload from `code/` or won't reproduce is disqualified. This plan closes both.
Output: `__getstate__`/`__setstate__`, deterministic id assignment, VP-3 green, VP-5 (double-run byte-identical) green.
</objective>
