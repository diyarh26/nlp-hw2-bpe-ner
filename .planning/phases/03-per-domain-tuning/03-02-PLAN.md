<objective>
Define and execute the VM-only F1 scoring step for the six candidate tokenizers, preserving the 10-hour Tesla M60 budget and recording best F1 per candidate for selection.
</objective>

## Artifacts this phase produces (this plan)

- `.planning/phases/03-per-domain-tuning/03-VM-F1-RUNBOOK.md`
- `tuning/results/vm_f1_results.csv`
- `tuning/logs/vm_f1/tokenizer_{1,2}_vocab{4000,8000,16000}.log`

<must_haves>
  <truths>
    - "F1 scoring is performed on the Tesla M60 VM, not locally."
    - "The VM runbook contains exactly six `code/train_ner_model.py` commands: 2 domains x 3 vocab sizes."
    - "Tokenizer 1 candidates use `data/ner_data/train_1_binary.tagged` and `data/ner_data/dev_1_binary.tagged`."
    - "Tokenizer 2 candidates use `data/ner_data/train_2_binary.tagged` and `data/ner_data/dev_2_binary.tagged`."
    - "`vm_f1_results.csv` records best F1, log path, runtime, and status for every candidate."
    - "The runbook states the VM budget assumption and the stop rule if first runs exceed the budget."
  </truths>
  <prohibitions>
    - "Do not run `code/train_ner_model.py` locally during Phase 3 planning or CPU execution."
    - "Do not change NER hyperparameters or edit `code/train_ner_model.py`."
    - "Do not continue spending VM time if the first two runs average more than 60 minutes each without Claude/user confirmation."
  </prohibitions>
</must_haves>
