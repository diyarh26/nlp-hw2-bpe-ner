    Create `code/select_tok3.py` as a dependency-free selector with `--cpu_csv`, `--vm_csv`, `--output_csv`, and `--candidate_dir`. For remaining candidates, compute a hidden-generalization score using the research formula: 0.35 mean visible F1 normalized higher-is-better, 0.25 combined visible tokens-per-char normalized lower-is-better, 0.15 domain-balance normalized lower-gap-is-better using F1 and tokens-per-char gaps, 0.10 OOV robustness, 0.10 reconstruction/alignment gate, and 0.05 speed normalized higher-is-better. Apply tie-breakers in order: smaller vocab when score difference is below 0.01, lower combined visible tokens/char, higher worst-domain F1, then higher speed. Write `tuning/results/tok3_selection.csv` with one row per vocab and columns for all score components, final score, gate status, gate reason, and selected boolean.
  </action>
  <verify>
    <automated>py -m uv run python code/select_tok3.py --cpu_csv tuning/results/tok3_cpu_sweep.csv --vm_csv tuning/results/tok3_vm_f1_results.csv --output_csv tuning/results/tok3_selection.csv --candidate_dir tuning/tokenizers</automated>
  </verify>
  <acceptance_criteria>
    - `tuning/results/tok3_selection.csv` contains vocab sizes `4000`, `8000`, and `16000`.
    - Exactly one row has `selected` equal to `true`.
